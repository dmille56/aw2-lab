* Scope and completion rules

Implement the first playable release defined in [[file:PLAN.md][PLAN.md]]: one active
local match, two trusted external players, one built-in Versus map, fixed COs,
and fog disabled. Both armies use external control through the server. AW2
remains authoritative for movement, combat, randomness, and victory.

This checklist describes planned work. Existing emulator primitives and
Milestone 2 decoding are prerequisites, not completed Milestone 3 integration.
Mark tasks complete only after their implementation and relevant checks pass;
record live evidence separately from synthetic checks. Keep ROMs, saves,
screenshots, and machine-specific paths outside Git and the Nix store.
